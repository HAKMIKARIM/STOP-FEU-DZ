ضبط قواعد أمان Firestore للتخزين المباشر

إذا كانت قاعدة البيانات السحابية ترفض الحفظ المباشر، يرجى التوجه لـ Firebase Console ثم اختيار Firestore Database > Rules ولصق الكود التالي: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

ملاحظة: يمكنك أيضاً دمج أمان محدود باستخدام التاريخ كالتالي:
allow read, write: if request.time < timestamp.date(2026, 8, 26);
